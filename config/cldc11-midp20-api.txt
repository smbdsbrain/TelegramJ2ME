# CLDC 1.1 (JSR 139) + MIDP 2.0 (JSR 118) API surface, plus the optional JSRs we
# probe for at runtime. Consumed by tools/check-api.py.
#
# [allow-classes]  exact internal names. Anything a device class references and
#                  that is not listed here (and is not one of our own classes)
#                  fails the build.
# [deny-members]   members that DO exist in J2SE but NOT in CLDC 1.1, on classes
#                  that are otherwise allowed. Optional ":descriptor" suffix
#                  pins a specific overload - that is how autoboxing is caught.
#
# Authority note: this file is a hand-maintained approximation of the specs. It
# is the enforcement mechanism only in the fallback bootclasspath mode (no WTK).
# When WTK_HOME is set, javac compiles against the real cldcapi11.jar +
# midpapi20.jar and that is exact; this file then acts as a second opinion.
