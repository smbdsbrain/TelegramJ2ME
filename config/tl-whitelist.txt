# Telegram API surface this client generates code for.
#
# tools/generate-tl.py takes the transitive closure of these and emits a
# descriptor table for exactly that closure - nothing else. Generating all 1546
# constructors would bloat the JAR past what a 2011 handset may accept and waste
# heap on types we never touch.
#
# Adding a method here is cheap; the closure grows only by what it actually
# references.
